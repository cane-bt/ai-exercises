# 業務日報台帳

システム運用の1日を「チェックリスト・対応ログ・引き継ぎ・振り返り」で回すための、ブラウザだけで動く台帳です。
HTML ファイル1つで動き、サーバもログインも要りません。記録は `localStorage` に保存されます。

## 解決したいこと

| 困りごと | この台帳での対応 |
| --- | --- |
| 作業の抜け漏れ | 予定時刻を過ぎた未完了を「遅れ」と表示する。前日の未完了と対応中のログを自動で繰り越す。毎週・毎月の定期作業はその日だけ出す |
| 時間の把握 | 項目・ログごとに計測（開始/停止）。定型・当日追加・対応ログの内訳を出す |
| 引き継ぎ・共有 | 対応ログ（時刻・事象・対応・状態）と、引き継ぎメモのワンクリックコピー。「明日の先頭タスク」は翌日の画面に申し送りとして表示する |
| 振り返り・集計 | 週・月のサマリー（完了率、遅れ、所要時間、よく遅れる項目・よく残る項目）と CSV 書き出し |

## 使い方

`index.html` をブラウザで開くか、このディレクトリで簡易サーバを起動します。

```bash
python3 -m http.server 4173
```

[http://localhost:4173](http://localhost:4173) を開いてください。

まず試すときは、右下の「データ」パネルで **サンプルデータを入れる** を押します。直近3週間の平日の記録ができるので、「振り返り」タブで集計を確かめられます。サンプルを入れると今の記録は置き換わるので、必要なら先に JSON で書き出してください。

### 画面

- **日次**
  - 始業 / 日中 / 終業 / 当日追加のチェックリスト（予定時刻・遅れ表示・繰越の印つき）
  - 対応ログ：対応中 / 完了の切り替え、その場での編集
  - 所要時間の計測と内訳。時間の数字を押すと手で直せる
  - 引き継ぎ：明日の先頭タスク、当日メモ、引き継ぎメモのコピー、印刷
  - 定型テンプレの編集：項目名・予定時刻・繰り返し（毎日 / 毎週◯曜 / 毎月◯日・末日）
- **振り返り**
  - 週（月曜始まり）/ 月の切り替え。前後の矢印で期間を移動する
  - 日別の表。行を押すとその日を開く
  - CSV 書き出し（BOM 付き UTF-8 なので Excel でそのまま開ける）

### キーボード

| キー | 動作 |
| --- | --- |
| `N` | 項目の追加欄へ移動 |
| `L` | 対応ログの入力欄へ移動 |
| `T` | 今日へ戻る |
| `[` / `]` | 前 / 次へ（振り返りでは週・月単位） |
| `V` | 日次と振り返りを切り替える |

## データ

- 保存先はこの端末のブラウザ内（`localStorage` のキー `ops-day-checklist-v1`）だけです。ブラウザのデータを消すと記録も消えます。
- 「データ」パネルから JSON で書き出し・読み込みができます。バックアップや別の端末への移行に使ってください。
- 旧版（v1）のデータは、開いたときに自動で新しい形式（v2）へ移行します。

## つくりについて

- 外部ライブラリは使っていません（使っている外部リソースは Google Fonts だけ）。
- ユーザーの入力は `textContent` と `value` だけで画面に出しているので、項目名に HTML を書いても実行されません。
- CSV では、`=` `+` `-` `@` で始まる値の先頭に `'` を付けています。表計算ソフトで開いたときに数式として実行されないようにするためです。
